# Hello GitHub! - 웹페이지 프로젝트 (网页项目)

Google Antigravity IDE를 활용하여 제작한 웹페이지 실습 프로젝트입니다.  
本项目为使用 Google Antigravity IDE 开发的网页实践项目。

---

## 1. 작품명 / 项目名称
- **Hello GitHub!** 개인 소개 및 Git 실습 웹페이지  
  **Hello GitHub!** 个人介绍与 Git 实践网页

## 2. 목적 / 项目目的
- Google Antigravity IDE 환경에서 바이브 코딩으로 웹페이지를 제작하고, 로컬 Git 저장소와 GitHub 원격 저장소를 연동하여 버전 관리 및 배포 실습을 수행합니다.
- 在 Google Antigravity IDE 环境下通过氛围编程（Vibe Coding）制作网页，并连接本地 Git 仓库与 GitHub 远程仓库，完成版本管理与部署实践。

## 3. 주요 기능 / 主要功能
- 반응형 웹 디자인 (Responsive Web Design / 响应式网页设计)
- 한국어 및 중국어 병기 안내 (韩中双语展示)
- GitHub 원격 저장소 및 GitHub Pages 배포 연동 가능 (支持 GitHub Pages 部署)

## 4. 실행 방법 / 运行方法
1. 이 저장소를 클론하거나 다운로드합니다.  
   克隆或下载此仓库。
   ```bash
   git clone https://github.com/Yongyule26/111111.git
   ```
2. 웹 브라우저(Chrome, Edge 등)에서 `index.html` 파일을 엽니다.  
   在网页浏览器（Chrome, Edge 等）中打开 `index.html` 文件。
